- ### Abstract
	- characterize features that are represented by human language cortex
	- essentially what its saying is
		- AI LMs have hidden states; if we use SAE features, they are hierarchically organized features which can be more clear predictors
		- so the paper was able to produce interpretations of neural responses 
			- used this to test model brain alignment
				- essentially, we take hidden states from the model and use a linear regression model to fit them to brain data for the same text and see how it predicts brain data
				- this paper looks into if this alignment model reflects the primary variation (top principal components: syntax vs semantics, position in a sentence, etc.)
				- vs idiosyncratic variations (variance caused by model and its set parameters that dont exist across other models)
					- an alignment model that predicts primary variation gives more insight
	- paper shows that fronto-temporal human language network is predicted by common set of features across regions
		- frontal regions explained well by surprisal alone
			- what is surprisal: surprisal measures how unexpected a word is given the words before it. it's the negative log of the probability of the current words given the previous words
			- used as an indicator; surprising words when read cause longer response and bigger brain activity
			- researchers use surprisal as a baseline: is the model just understanding the odds of what word comes next or is there something more?
		- voxels:
			- "volume pixels": 3D units fMRI divides the brain into
			- fMRI measures BOLD: blood oxygenation --> neural activity for each voxel over time
			- caveat: it's slow; BOLD lags behind neural response
	- paper says brain responses are best explained by features that tend to capture most general information encoded in LM representations; nontrivial correspondence
- ### Introduction
	- criticisms: relating two black boxes together, LMs and the brain; dont yield clear claims about what neural populations represent or compute
	- two developments
		- sparse autoencoders, which provide a tool for decomposing dense LM hidden states into latent features --> more identifiable and easier to interpret than residual stream features
		- neuroimaging work: delineated fronto-temporal language network
			- essentially means they've mapped out the sections of the brain that correspond to language processing and understanding
	- propose new encoding model: **augmented sparse encoding models**
		- normal setup:
			- feature extractor: run each sentence through an LM, take hidden states from a middle layer, and average over tokens
			- what does this mean?
				- there are many layers within a network that build up the meaning of a sentnece.
				- first layers might interpret what each word means individually
				- middle layers undersatnd semantics of a sentence and how placements of certain words might change certain meanings
				- last layers focus on predicting the next word
				- the hidden state (residual stream) is the vector that is added to throughout these layers to keep track of this learned information
					- we take the middle layer because it contains the most information
				- **mapping to voxels:** fMRI gives one reading per one voxel per sentence; LMs give one vector per token; to align them we need one vector per sentence, so we average the token vectors to get one vector per sentence
		- **what they change:**
			- swap dense features for SAE features: pass hidden states into sparse autoecndoer's encoder: maps 2304-d vector into 32k-d space where only a few features are active at a time
				- these features tend to be monosemantic and lableable: "relationships", "semantics", "understandign", etc.
				- regression then uses SAE features instead of raw dimensions
			- "augment" with surprisal
				- add sentence's average surprisal from LM as a feature
				- separates
					- voxel responds to how hard the sentence is to process
					- voxel responds to what the sentence is about
			- this allows them to characterize the properties of the features that drive alignment
			- so they then want to identify **whether brain alignment relies on primary or idiosyncratic LM feature dimensions**
- ### Methods
	- **Brain Data**
		- used brain responses from prior work
			- 8 english speakers underwent ultra-high-field 7 Tesla fMRI while listening to 200 diverse sentences, each repeated 3 times in random order
			- modeled BOLD response with General Linear Model
			- single value per voxel per sentence
				- averaged over three repetitions of a sentence
		- selecting voxels used:
			- if voxel is part of fronto-temporal language network
			- based on two principal components
				- PC1: processing difficulty characterized by frequency and surprisal
				- PC2: concrete-abstract content, degree to which a sentence's meaning is gounded in perceptual experience
		- define five populations
			- hard to process - high pc1
			- easy to process - low pc1
			- abstract - high pc2
			- concrete - low pc2
			- ghost - weak on both
			- this makes sense intuitively
		- selected five relevant portions of the brain i think
			- inferior frontal gyrus
				- orbital portion
			- middle frontal gyrus
			- anterior temporal and posterial temporal
	- **Augmented Sparse Encoding Models**
		- defined by two components:
			- feature exctractor that transforms language stimuli to a feature vector
			- linear readout that maps feature vector onto neural responses to the same linguistic stimuli
		- employed SAEs to transform dense residual-stream LM representations into much larger and interpretable feature basis
		- also added dedicated feature that encodes average surprisal (negative log likelihood) of a sentence
		- **analyzed two different SAE architectures**
			- JumpReLU and Matryoshka
				- Jump is common high performing - standard SAE
				- Matry SAE adds more structure - learns more features
					- later features capture finer-grained features
				- JumpReLU SAEs from Gemma Scope release
					- 16.4K dim
				- Matry is 32K dim
- ### Study 1: Validating Augmented sparse encoding models using pc-derived voxel subtypes
	- four pc-derived voxel subtypes: hard, easy, abstract, concrete
		- pc interpretations obtained via small set of manually collected (human-derived) annotations
			- so they're already characterized
			- now all we need to do is ask whether interpretations obtained from the encoding models lines up with these characterizations
	- **findings:**
		- 1. SAE features tend to predict voxel responses to language stimuli nearly as well as dense LM residual features
			- a little confusing but LM residual features arent understandable but they predict well; SAE features predict brain about as well **and** you can read what they mean
		- 2. dissociation between processing difficulty driven and content driven voxel regimes
			- voxels in hard to process subttype captured by surprisal alone
				- no improvement from sae or residual stream features
			- abstract and concrete subtypes benefit from inclusion of sae or residual stream features
			- breaking this down:
				- for every voxel, two models are fit:
					- **surprisal only**: one number per sentence (how unxepected it is) -> guess voxel's response
						- if a sentence is expected, predicts low voxel activation
						- if unexpected, predicts high activation
					- ==🔴question: could this be circular reasoning because hard to process group was determined by surprisal so it could be reason why it was predicted by surprisal==
					- **surprisal + sae features**: same number plus around 18 content features -> guess voxel's response
						- sae adds more about what the sentence means; abstract voxels respond to that; surprisal cant capture that
			- **this finding gives evidence about what data every voxel used which gives insight into roles within regions of the brain**
		- 3. identifying which features each voxel uses, now that we know SAE features help for abstract and concrete voxels
			- for each abstract and concrete voxel, they ran regression and looked at which SAE features got picked and whether they had a + or 0 sign. then they counted how often each feature showed up across all voxels
				- + vs - sign: in regression, each feature gets a weight
					- so +: when feature is active, voxel response goes up
					- (-): when feature is active, voxel response goes down
			- found that abstract and concrete voxels use different features
				- abstract
					- go up for emotion sentences and down for scenery sentences
					- concrete show roughly the opposite
			- also found that out of 32k possible features, small handful keeps getting picked
			- also found it not to be a mirror image between abstract voxels and concrete voxels; one being dormant did not necessarily mean that the other was active
- ### Study 2: Identifying and interpreting uncharacterized voxel populations
	- applying augmented sparse encoding models to idenfity coherent voxel subpopulations and interpret them from Ghost subtype, group that was not classified from two main PCs
	-  **Findings:**
		- 1. most of the voxels in the ghost voxel set couldnt be predixted by surprisal or lm/sae representations; **however** there was a small subset of 32 voxels that signed features could predict and generalize to other voxels
			- consistent with a shared underlying feature basis
		- 2. coherent ghost subpopulation is tuned to people-centered content
			- fit augmented sparse encoding models to each voxel
			- found features used to predict this voxel subpop are driven by sentences that include 'people-specific' features
				- discussions of relationships/emotions
				- people taking cnocrete actions
				- pronouns
			- these voxels were located outside traditional frontal and temporal areas for language
- ### Study 3: Characterizing the Feature Basis of the front-temporal language network
	- investigating if differences in representational code exist between five canonical left lateralized language regions
	- **Findings:**
		- 1. language regions show mixed tuning to processing difficulty and content, but not uniformly across regions
		- 2. language network voxels draw on a common feature basis with graded participant-specific variation
			- is human language network organized around a shared feature basis or a more sharply separated regional and participant specific feature space?
			- found that entire language network is organized around a shared, dominant feature set consisting of both content and form linked features
				- small cross particpant core
				- broader regime of features reused across only subsets of participants
					- reflect individual variation in linguistic representations
- ### Discussion
	- **Conclusion:**
		- ASEM improve on prior approaches that treat models and brains as black boxes
			- results show small sets of features can be used to predict brain responses to language
		- regions of language network differ in processing difficulty vs content
	- **three implications of findings**:
		- 1. the nature of linguistic representations: a shared feature basis
			- found small sets of signed SAE features selected to predicted one voxel generalize strongly to voxels in other functional regions of interest
			- found small s et of core features also appear across *individuals* 
		- 2. people-centered content outside the dominant language dimensions
			- identified people-centered subpopulation voxel cluster that was predicted by features related to relationships, pronouns and actions involving people
				- in Ghost pc group analysis
		- 3. general LM features predict brain responses
			- matryoshka sae's 32k features come in groups (bins)
				- bin 1: features 0-128 - most general features; can roughly rebuild LM's hidden state
				- bin 2-5: 128 - 32k - finer details, each bin cleaning up what earlier bins missed
			- found that:
				- 1. regressions mostly picked general features
				- 2. general features alone beat everything else
					- restriced LMs to single bin; 128 general faeetures predicted best, better than any finer bin
				- 3. not a trick of empty features
					- thousands of fine grained features do fire so discrepancy is not caused by finer grained features just not firing
- ### Limitations
	- 1. choice of SAE
		- interpretations are limited to feature basis of SAE
	- 2. limitations of neural data
		- voxels encompass hundreds of thousands of neural data
		- collecting neural data for larger set of diverse stimuli will enable further investigation of feature tuning during language processing
