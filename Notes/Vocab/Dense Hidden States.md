# Dense Hidden States

**In one line:** the raw internal numbers of an LLM at a given [[Layer|layer]] — one vector per token, before any SAE un-blending.

**"Dense" vs "sparse":** dense = all numbers active and entangled ([[Superposition|superposition]]); sparse = the SAE version where only a few [[Feature|features]] fire.

**Why we care:** the benchmark for Claim 1 — do interpretable SAE features predict the brain *about as well* as these raw dense states?
