# Permutation Test

**In one line:** test significance by **shuffling** the data many times to build a "by chance" distribution, then checking whether the real score beats it — no parametric assumptions.

**Why we care:** brain scores violate normal-distribution assumptions; permutation tests give honest significance. Combine with [[Contiguous Train-Test Split|contiguous splits]] so the shuffle respects time structure.
