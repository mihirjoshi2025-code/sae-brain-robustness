# Lexical Features

**In one line:** [[Feature|features]] about **word form / spelling** — sub-word pieces like "-tion" or "-ment," not meaning.

**Why we care:** the papers report lexical features contribute ~zero to brain prediction and dominate the **bottom** [[Layer|layers]]. Part of the taxonomy contrast for Claim 2.
