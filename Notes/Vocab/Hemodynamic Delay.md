# Hemodynamic Delay

**In one line:** blood flow responds to neural activity with a **lag of a few seconds**, so the [[fMRI]] signal for a word shows up seconds after the word.

**Why we care:** the [[Encoding Model|encoding model]] must account for this by including **delayed copies** of the features (finite-impulse-response / lagged predictors). Getting this right is core to the pipeline.
