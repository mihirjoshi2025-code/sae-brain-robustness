# Ridge Regression

**In one line:** linear regression with a "don't overfit" penalty — the standard workhorse for fitting [[Encoding Model|encoding models]] when you have many features and limited data.

**Why ridge:** feature sets are huge (thousands of [[Feature|features]]) and brain data is limited; the penalty keeps weights sane. Runs on CPU.

**Tool:** [[himalaya]] (built for voxelwise ridge at scale).
