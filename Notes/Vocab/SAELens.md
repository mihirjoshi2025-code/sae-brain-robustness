# SAELens

**In one line:** a Python library for **loading and running public [[Sparse Autoencoder (SAE)|SAEs]]** (like [[Gemma Scope]] and [[Llama Scope]]) on model activations.

**Why we care:** the suggested tool for the **Feature extraction** workstream — standard way to pull SAE features without re-training SAEs.
