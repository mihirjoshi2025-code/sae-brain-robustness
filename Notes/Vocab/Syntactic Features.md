# Syntactic Features

**In one line:** [[Feature|features]] about **grammar** — words like "who," "which," "that," and structural roles.

**Why we care:** in the taxonomy they're the contrast class to [[Semantic Features|meaning]]; the papers report they add only a little to brain prediction. Our grid checks whether that holds.
