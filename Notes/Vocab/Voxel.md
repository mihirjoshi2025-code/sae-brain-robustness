# Voxel

**In one line:** a 3D pixel — the smallest cube of brain the [[fMRI]] scanner measures (typically a few mm per side), each with its own activity time-series.

**Why we care:** the [[Encoding Model|encoding model]] predicts each voxel's activity from model features ("voxelwise encoding"). Grouping voxels gives [[Cortical Regions|cortical regions]] for Claim 3.
