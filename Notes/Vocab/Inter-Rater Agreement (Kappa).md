# Inter-Rater Agreement (Kappa)

**In one line:** a number (Cohen's/Fleiss' **κ**) measuring how much two labelers **agree beyond chance** — 1.0 = perfect, 0 = chance-level.

**Why we care:** the [[Feature Taxonomy|taxonomy]] drives Claim 2, so we must show the labels are reliable. **Gate B requires κ ≥ 0.7.** Report it for the 200-feature validated sample.
