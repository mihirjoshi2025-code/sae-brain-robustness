# Cortical Regions

**In one line:** named areas of the brain's surface (cortex) that tend to do particular jobs — e.g., anterior temporal lobe for emotions, angular gyrus for objects/space.

**Why we care:** Claim 3 says different [[Feature|feature]] categories map onto distinct regions. We check whether the same category→region mapping holds across the grid.

**Caveat:** the source paper used a **generic atlas**, not each subject's own language areas, which weakens region-vs-region claims.
