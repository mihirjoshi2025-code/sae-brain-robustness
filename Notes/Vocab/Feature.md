# Feature

**In one line:** one "thing" an [[Sparse Autoencoder (SAE)|SAE]] has learned to detect — e.g., a feature that fires for physical objects, or one for emotions, or one for the word-ending "-tion".

**Example categories (from the papers):** objects, emotions, social/mental content, places/space, grammar words, word-pieces.

**Why we care:** features are sorted into buckets by the [[Feature Taxonomy|taxonomy]] to test whether [[Semantic Features|meaning]] features do most of the brain-predicting (Claim 2).
