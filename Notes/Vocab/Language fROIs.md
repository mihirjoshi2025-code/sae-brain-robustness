# Language fROIs

**In one line:** a person's own **language-network regions**, found with a functional localizer (e.g., reading sentences vs. nonword lists) rather than by anatomy alone.

**In our data:** [[Pereira 2018]] ships these per participant (`languageLH`, `languageRH`: posterior/anterior temporal, angular gyrus, IFG, IFG-orbital, MFG). The files don't document exactly how they were derived, so treat that detail as unverified. The frontal ones (IFG, IFGorb, MFG) are the "frontal language regions" in claim 4. We use the LH+RH union as the headline voxel set for Pereira scores.
