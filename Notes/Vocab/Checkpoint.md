# Checkpoint

**In one line:** a saved snapshot of a model at a particular point in training.

**Why we care:** the **stretch goal** uses checkpoints (e.g., [[Pythia]]'s many saved steps) to study how brain alignment changes *across training* — only if we're ahead of schedule at Gate C.
