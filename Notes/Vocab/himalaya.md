# himalaya

**In one line:** a Python library for **voxelwise [[Ridge Regression|ridge regression]]** at scale — the suggested tool for the encoding pipeline.

**Why we care:** fits encoding models for thousands of [[Voxel|voxels]] efficiently, with built-in cross-validation for the ridge penalty. Pairs with the Gallant lab voxelwise tutorials for onboarding.
