# Semantic Features

**In one line:** [[Feature|features]] about **meaning** — objects, emotions, social/mental content, places/space, events.

**Why we care:** Claim 2 says semantic features give ~**94%** of encoding performance; Claim 3 says their sub-types map onto [[Cortical Regions|brain regions]]. The headline "it's meaning" story.

**Contrast with:** [[Syntactic Features]] (grammar) and [[Lexical Features]] (word-form), which the papers say contribute little.
